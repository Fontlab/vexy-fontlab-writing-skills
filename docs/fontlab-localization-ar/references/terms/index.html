    Arabic terms¶

    Portable term table, snapshot of 04 October 2026, generated from the core translation memory localization/ar-core.tmx of the FontLab writing guide by tools/scripts/export_terms.py. 52 of 289 terms are approved or protected; a proposed translation is a candidate for a native reviewer, and the English term is the fallback until it is approved. Use newer supplied project data when it disagrees with this snapshot.

    A status of do-not-translate protects the English spelling; it does not approve a draft English name. The definition says what the term means in FontLab; the note says why the translation was chosen or how to inflect it. The fallback original term is a plain English phrase to translate instead of the term when the term itself will not travel (stem: main stroke; overshoot: optical surplus).

    Type design¶

    English Fallback Arabic Status Note Definition
    ascender upward extension صاعد proposed 29LT's Arabic type-anatomy article (الصاعد) and the TypeType glossary (الصاعدة); the traditional pair صواعد/نوازل. Rejected Glyphs 3 Arabic خط السقف. An ascender is the part of a lowercase letter that extends above the x-height, as in b or d. Ascender height describes the intended alignment of these parts and may differ from cap height. Do not confuse this design measurement with similarly named vertical metrics in exported font tables. Line spacing depends on those fields and on the application using them.
    baseline writing line خط الأساس proposed Glyphs 3 Arabic and Adobe use خط الأساس; TypeType has الخط الأساسي. Rejected 29LT's خط الارتكاز as less common in software. A baseline is a reference line used to align text. In conventional horizontal Latin font design, the baseline is at y = 0, with ascenders above it and descenders below it. Other scripts and layout systems can use different baseline conventions. Identify the relevant baseline when discussing alignment across scripts or vertical text.
    bowl round belly بطن الحرف proposed No settled term; fallback 'round belly' translated. Rejected سلطانية (kitchen bowl), TypeType's descriptive الشكل البيضاوي and the calligraphic كأس, which names the open cup of letters such as ن. A bowl is a rounded stroke that encloses a counter, as in b, d or p. Its shape, thickness and junctions affect the letter's balance. The appropriate number of curve segments depends on the design. Nodes at extrema can help editing and hinting, but a fixed segment count does not guarantee compatible masters or good interpolation.
    cap height capital-letter height ارتفاع الأحرف الكبيرة proposed 29LT (خط ارتفاع الحرف الكبير) and TypeType (ارتفاع الحروف الكبيرة). Rejected Glyphs 3 Arabic ارتفاع الغطاء, which translates cap as lid. Cap height is the distance from the baseline to the top of a flat capital such as H. Rounded or pointed capitals may extend beyond it through overshoot. Record the intended value in Font Info. Cap height describes a design measurement; alignment zones and line-spacing metrics are separate settings, even when their values are related.
    character حرف proposed Adobe and Apple Arabic use حرف/أحرف for character; keeping حرف here leaves محرف free for glyph, the distinction the definition requires. Plural أحرف. A character is an abstract unit of written text, such as a letter or punctuation mark. A glyph is its visual representation. The relationship is not one to one: several characters can form a ligature, and a character can have several glyph forms. A user-perceived character can also consist of several Unicode codepoints. Keep characters, codepoints and glyphs distinct when discussing encoding or text processing.
    contour مسار proposed Glyphs 3 Arabic (مسار for path), Adobe Illustrator Arabic and TS Fonts (مسارات) use مسار for a sequence of connected segments. Rejected Glyphs' long خط كنتوري and the corpus pick محيط. A contour is an open or closed sequence of connected line and curve segments. Its nodes and control points describe its geometry. One glyph or vector object can contain several contours. A counter is an area of space, not a synonym for a contour. When explaining fill behaviour, identify the outline format and fill rule before prescribing a contour direction.
    counter enclosed white space فراغ داخلي proposed TypeType Arabic glossary: الفراغ الداخلي. Rejected the corpus pick عداد, the counting device. A counter is the enclosed or partly enclosed space within a letterform, such as the enclosed space in an o or the open space in a c. The surrounding strokes define it. A closed counter may have an inner contour as its boundary; an open counter does not require a separate contour. Judge its size and shape together with the surrounding strokes.
    descender downward extension نازل proposed 29LT's Arabic type-anatomy article and the TypeType glossary both use النازل. Rejected Glyphs 3 Arabic خط القاع. A descender is the part of a letter that extends below the baseline, as in p or y. Its design height is usually recorded as a negative coordinate relative to the baseline. Exported descender metrics are separate fields used by applications for layout. Whether a deep glyph clips depends on the relevant metrics, application and text container, not on one design value alone.
    diacritical mark combining mark علامة تشكيل proposed Apple CoreText (علامات تشكيل) and the TypeType glossary (العلامات التشكيلية); the same word Arabic uses for its own vowel marks. A diacritical mark is a small sign, such as an acute or a cedilla, that attaches to a base letter to form another character. FontLab builds accented glyphs from a base and a mark through anchors, and the GDEF mark class tells the shaper which glyphs are marks. Say mark glyph for the class member and diacritical mark for the sign.
    em type body em proposed Adobe InDesign Arabic help and Glyphs 3 Arabic (الوحدات لكل Em) both leave em in Latin script; Arabic typesetting has no settled word for it. Rejected TypeType's مربع الـ Em and the transliteration إم. The em is the square on which a typeface is designed, historically the body of the letter M in metal type. Its height equals the type size, so an em in 12 point text is 12 points. In a digital font the em is divided into UPM font units.
    extremum local extreme point نقطة قصوى proposed TypeType Arabic glossary: النقاط القصوى; also the mathematical term. An extremum is a point where a curve reaches a local leftmost, rightmost, topmost or bottommost position. The plural is extrema. Placing nodes at extrema can help editing and hinting. If you add nodes to masters intended for interpolation, preserve the correspondence between their contours and points. Different extremum positions alone do not make masters incompatible.
    glyph محرف proposed Glyphs 3 Arabic uses محرف/المحارف throughout, and Khalid Alabdullah's Arabic type blog says the profession calls glyphs المحارف. Rejected صورة حرف (Apple Font Book), حرف رسومي (Adobe) and the loan غليف (TypeType); note that general Arabic computing sometimes uses محرف for character. A glyph is one drawn shape in a font: a letter, a figure, a mark, or a piece of a composite. A character is what a reader types and a glyph is what a renderer draws, and one character can map to several glyphs while several characters can map to one. You edit a glyph in the Glyph window, where its contours, elements, anchors, and metrics all live together. The distinction matters in any sentence about encoding, since a font maps codepoints to glyphs through the cmap table.
    handle مقبض proposed Inkscape Arabic and Adobe Illustrator Arabic (مقابض اتجاه) use مقبض, plural مقابض. A handle is an off-curve control point used to shape a curve segment. A cubic Bézier segment has two control points; a quadratic segment has one. Moving a handle changes the curve without moving its endpoints. In tools that display handle arms, the arm connects a control point to an endpoint. Name the curve type when the number or behaviour of handles matters.
    ink trap ink relief notch مصيدة حبر proposed TypeType Arabic glossary: مصيدة الحبر, plural مصائد الحبر. An ink trap is a notch cut into a corner where strokes meet, so ink spread or rasterization at small sizes does not clog the join. FontLab makes them as a live Smart Corner variant.
    italic angle slant angle زاوية الميل proposed Glyphs 3 Arabic: زاوية الميل. The italic angle is the slope of the upright strokes of an italic or oblique design, measured from the vertical in degrees. FontLab stores it in Font Info, uses it to slant guides and the cursor, and writes it into the post and hhea tables. It is a property of the design, not of a transformation.
    lining figures capital-height figures أرقام مرصفة proposed Glyphs 3 Arabic: أرقام مرصفة. Apple has أرقام مصفوفة and TypeType الأرقام المصطفة. Lining figures are digits that share the cap height and sit on the baseline, so they align with capitals in tables and headlines. The lnum feature selects them where a font defaults to oldstyle figures.
    node عقدة proposed TS Fonts (Arabic foundry) writes عقد for nodes; Inkscape, Blender and Visio Arabic use عقدة. Glyphs 3 Arabic uses نقطة, rejected because FontLab must keep node apart from on-curve, off-curve and control point (نقطة). A node is a point on a contour where segments meet, and its type decides how they meet. A sharp node lets two segments arrive at any angle. A smooth node keeps the handles collinear so the curve passes through without a kink. A tangent node joins a line to a curve smoothly. A G2 node matches curvature as well as direction. You select a node and drag it, or nudge it, and the segments on both sides follow. Put nodes at the extremes so hinting and interpolation have something to hold.
    overshoot optical surplus امتداد بصري proposed The TypeType Arabic glossary defines الامتداد البصري as exactly this; it also matches the fallback 'optical surplus'. Rejected تجاوز, which reads as skip or override in UI. Overshoot is the extension of a rounded or pointed shape beyond an alignment line so that it appears as tall as a flat shape. For example, an o may extend above the x-height and below the baseline. Its amount depends on the design and intended size. PostScript alignment zones can describe these overshoot regions for hinting; there is no universal percentage to apply.
    proportional figures natural-width figures أرقام نسبية proposed Glyphs 3 Arabic and Apple CoreText: أرقام نسبية. Proportional figures have individual advance widths, so a 1 takes less room than an 8. They read well in running text; tabular figures share one width for columns. The pnum feature selects them.
    segment قطعة proposed The mathematical term for a segment and attested in the corpus; Glyphs 3 Arabic has جزء, rejected because it reads as any part. A segment is the portion of a contour between two on-curve endpoints. It may be a straight line or a curve. A quadratic Bézier segment has one off-curve control point; a cubic segment has two. Describe the segment type and the relevant editing command rather than assuming that every curve has two handles or that changing a node type performs every conversion.
    serif ذنابة proposed The TypeType Arabic glossary has الذنابة, and Apple CoreText's دون ذبانة looks like a misspelling of the same word. Rejected 29LT's تذييل and Font Book's مذيل because حرف مذيل is the swash in Glyphs and Adobe. A serif is the finishing stroke at the end of a stem or arm. Its shape sorts a face into the familiar classes: oldstyle, transitional, Didone, slab. You draw a serif once and reuse it as a component or an element, which keeps a family consistent and makes a late change cheap. Serifs are small, so they take the most damage at low resolution, which is where hinting and careful alignment zones earn their place.
    sharp حاد proposed Standard Arabic for sharp in Apple, Adobe and Microsoft. Sharp describes a pointed corner or a node at which contour direction can change abruptly. Image sharpening is a different operation.
    sharp node عقدة حادة proposed Derived from عقدة and حاد; no attestation of the compound. A sharp node joins contour segments without requiring a smooth change of direction. The handles of adjacent segments need not be collinear; a smooth node constrains their direction.
    stem main stroke ساق proposed Glyphs 3 Arabic (ساق, السيقان) and the TypeType Arabic glossary (الساق) agree. Feminine noun. A stem is a main stroke of a letter, usually the vertical one: the two uprights of an H, the single upright of an l. Stem width sets the weight of a face, and stems that disagree across a family break its rhythm. You measure a stem with the Measurement tool and record the standard widths in Font Info, where hinting and the stem links read them. Vextra reuses the word for the paired edges it detects in general artwork, not only in letters.
    swash flourish حرف مذيل proposed Glyphs 3 Arabic, Adobe Illustrator Arabic (الحروف المذيلة) and Apple CoreText (أحرف مذيلة) agree. Rejected TS Fonts' الحروف الممتدة and Apple's زخرفة. A swash is a decorative flourish that extends a letter, often on a capital or a terminal. Swash alternates live in the swsh feature and in glyphs with a swash suffix.
    terminal stroke ending نهاية proposed TS Fonts (النهايات) and the TypeType glossary (النهاية, نهاية الضربة). Rejected وحدة طرفية, the computer terminal. A terminal is the end of a stroke without a serif, such as the ending of a c or f. Its shape may be rounded, angled or cut off, depending on the design. Compare related terminals across a typeface at the intended reading size. The anatomical term does not prescribe how to construct or store the shape in an editor.
    UPM units per type body وحدات لكل em proposed Glyphs 3 Arabic: الوحدات لكل Em; the abbreviation UPM stays Latin in compact fields. Keep numeric controls compact: LSB/RSB (French AG/AD), UPM and PPM. Expanded terms belong in explanatory help; the full Family Dimensions Units Per eM label is an intentional exception. Team UI convention in Proteus 1751b28b0. UPM, units per em, specifies how many font units make up one em. It sets the scale for outline coordinates and metrics when a renderer converts them to a text size. Values such as 1000 and 2048 are common; TrueType outlines do not require a power of two. When changing UPM, distinguish changing the scale value from rescaling the outlines and metrics.
    winding direction drawing direction اتجاه المسار proposed Derived from مسار; Glyphs 3 Arabic has حدد الاتجاه for Set Direction. Winding direction is the order in which a contour runs, clockwise or counter-clockwise, and it decides which areas the renderer fills. FontLab follows the PostScript convention: outer contours wind counter-clockwise and counters wind clockwise. The letter O is two contours, one each way. You check direction before you export, and reverse a contour when a counter fills solid or an outer shape turns hollow. A renderer applies the rule at draw time, so the error shows in the proof rather than in the editor.
    x-height small-letter height ارتفاع x proposed 29LT writes ارتفاع الحرف إكس and TypeType ارتفاع الحرف x; shortened for dense panels. Rejected Glyphs 3 Arabic ارتفاع صلب الحرف, not found elsewhere. The x-height is the height of a lowercase x above the baseline, and it stands for the height of the lowercase in general. It does more for apparent size than the point size does: two faces at the same size look different when their x-heights differ. You record it in Font Info so hinting and alignment zones can use it, and you draw round letters slightly above it to allow for overshoot. Write it lowercase with a hyphen, even at the start of a sentence recast to avoid one.

    Font engineering¶

    English Fallback Arabic Status Note Definition
    advance height تقدم رأسي proposed No attestation; names the vertical advance directly, with Apple CoreText's رأسي for vertical. ارتفاع المحرف was rejected because it reads as the visible height. The distance the text position advances vertically after a glyph. It is the vertical counterpart of advance width, not the height of the visible outline.
    advance width glyph box width عرض المحرف proposed Glyphs 3 Arabic labels the advance simply العرض; عرض المحرف keeps it apart from the width axis and from a shape's geometric width. Rejected the unattested calque عرض التقدم. Advance width is the horizontal distance allocated to a glyph before layout adjustments, measured in font units. In an OpenType font, the base values are stored in the hmtx table. Kerning and other positioning operations can adjust advances during layout without rewriting those base values. Advance width differs from the visible outline width; a space can have an advance without an outline.
    alignment zone height band for snapping منطقة محاذاة proposed Glyphs 3 Arabic: مناطق المحاذاة. An alignment zone is a region around a common vertical alignment, such as the baseline or cap height, used in PostScript hinting. It can include the overshoot of rounded letters. A rasterizer uses zone information when fitting outlines to a pixel grid. Keep this mechanism distinct from design measurements and from the control-value and instruction mechanisms used in TrueType hinting.
    anchor attachment point مرساة proposed Glyphs 3 Arabic: مرساة, plural مراسي. Adobe's نقطة ربط names an anchor point on a path, which is a node, not this object. An anchor is a named attachment point in a glyph that says where a mark belongs. A base letter carries a top anchor, and the accent carries a matching one, so the accent lands in the same relation on every letter that uses it. You place anchors in the Anchors and Pins panel, and FontLab uses them both to build composites and to generate mark attachment lookups in GPOS, which is what positions marks in text the font never composed itself.
    anti-aliasing edge smoothing تنعيم الحواف proposed Fallback 'edge smoothing' translated; the common Arabic phrase in graphics writing. Rejected Krita's الصقل. Anti-aliasing paints partly covered pixels in intermediate shades so a rendered outline looks smooth. FontLab's preview can show anti-aliased, monochrome or subpixel rendering so you can check how hints behave under each. Write the hyphenated form.
    autohinting automatic screen fitting تلميح تلقائي proposed Glyphs 3 Arabic: التلميح التلقائي; same verbal noun as the command. Autohinting generates hints for a font from its outlines and its declared stems and zones, in one pass over the glyphs. It is a starting point rather than a finish: it hints the regular cases well and leaves the awkward glyphs for you. You run it after the alignment zones and standard stem widths are correct in Font Info, because it reads them. Then you check the glyphs that matter at text sizes and correct by hand what the pass got wrong.
    axis محور proposed Glyphs 3 Arabic and TS Fonts: محور, plural محاور. An axis is one dimension of font variation, such as weight, width or optical size. In an OpenType variable font, each axis has a four-character tag and a minimum, default and maximum value. Registered tags, such as wght, have defined meanings. Preserve tag spelling and case, and check the axis registry when assigning a custom tag.
    axis map axis value mapping تعيين المحور proposed Glyphs 3 Arabic: تعيينات المحاور for axis mappings. An axis map converts user coordinates on an axis, such as weight 400, to the design coordinates of the masters. It is stored in the avar table and lets a slider feel even when masters are not.
    bottom sidebearing هامش سفلي proposed Derived from هامش جانبي; the word for side is dropped because the bearing is vertical. The space below the glyph outline within its vertical advance. This value participates in vertical text spacing rather than horizontal spacing.
    component مكون proposed Glyphs 3 Arabic: مكون, plural مكونات. A component is a reference to another glyph placed inside this one, so that aacute holds the a and the acute rather than copies of their outlines. Change the source glyph and every glyph that references it follows. You build composites from components, position them with anchors, and keep them as references through to export, where a TrueType flavoured font stores them in the glyf table. In FontLab a component is one kind of element reference.
    composite glyph assembled glyph محرف مجمّع proposed Fallback 'assembled glyph' translated; the shadda disambiguates. Glyphs 3 Arabic and Font Book use مركب, rejected because حرف مركب is the ligature in Adobe and TS Fonts. A composite glyph is built from references to other glyphs rather than from its own outlines: an accented letter, a currency symbol with a bar, a stacked fraction. You assemble it from components and anchor them to the base, so a change to the base or to the mark reaches every composite that uses it. Composites keep a large accented character set consistent and small. A composite that has been decomposed is no longer one, and no longer follows its sources.
    conversion profile export settings set ملف تعريف التحويل proposed No attestation; ملف تعريف is the standard Arabic for a settings profile. Arabic uses تحويل for both conversion and transform. A conversion profile is the saved set of choices TransType applies to a conversion: the output format, the naming scheme, the filters, and the options that go with them. You build a profile once for a job you repeat, then run it over a new set of sources without repeating the decisions. It matters because a family converted with two different sets of options ships as two families that do not quite match, which shows up in a font menu rather than in a test.

    GSUB GSUB do-not-translate GSUB is the OpenType table containing glyph-substitution lookups. It supports operations such as replacing a glyph with an alternate, forming a ligature or selecting a form from its context. FontLab compiles feature code into these structures. To diagnose a missing substitution, check the glyphs, compiled rules, feature selection, language and shaping order in the target application.

    OpenType class layout glyph group فئة OpenType proposed Glyphs 3 Arabic uses فئة for classes.     Unicode codepoint character code نقطة ترميز Unicode proposed TypeType glossary and Arabic reference usage: نقطة ترميز; Unicode stays Latin as a standard's name. A Unicode codepoint is an integer from U+0000 to U+10FFFF. Not every codepoint has an assigned character. Write it with U+ and at least four hexadecimal digits, as in U+0041 for A. In a font editor, a glyph's Unicode assignment connects it to an encoded character; the exported cmap records the relevant mapping.

The pair is a variation sequence, mapped in the cmap format 14 subtable; a default mapping points at the base glyph.
    writing system نظام كتابة proposed Microsoft Arabic: نظام الكتابة. A writing system is the set of characters and rules a language writes with, such as Latin, Cyrillic or Arabic. OpenType calls it a script and identifies it by a four letter tag. Say writing system in prose and script tag for the identifier, so the reader does not confuse it with a Python script.
