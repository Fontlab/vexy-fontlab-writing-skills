    Channels: email, video, ads, comparisons, search and answer engines¶

    Fictional packets unless marked verified.

    Message match across a route¶

    [Hypothetical packet] Facts: an ad offers “a 30-day trial of the master view”. The landing page has a trial button. Checkout shows the trial terms.

    Ad: See every master of a glyph side by side. 30-day trial.

    Landing headline: Every master of a glyph, side by side: try it for 30 days

    Checkout line: 30-day trial, all features, watermark on export.

    The promise does not change shape between click and checkout. A landing page headed “The future of type design” would make the reader search for the thing they clicked.

    A welcome email that keeps its promise¶

    Facts: the reader downloaded a fictional sample-file pack. The list sends one email a month. Replies reach a named support person.

    Subject: Your sample files, and what to try first

    Here are the five sample files you asked for: [CONFIRM DESTINATION: download link]. Open 01-regular.ufo first; it has the master view set up.

    You will get one email a month: one technique, release notes when there is a release. Reply to this message if a file does not open; it reaches Anna in support. [CONFIRM: sender and reply route]

    Deliver the promised thing in the first lines, say what comes next and how often, and make replies real.

    Mostly useful, offers labelled¶

    A monthly newsletter can teach, show a technique, round up outside work and, when there is one, make an offer. Label the offer as an offer:

    Subject: Offer: version 5 upgrade at EUR 49 until 30 November

    A first frame that is the work¶

    Facts: a short clip shows one photograph turned into three line styles in a fictional line-art app.

    First frame: the three results side by side, with the caption “One photo, three line styles”.

    Next shot: the source photo, then the style menu.

    Avoid opening on a logo, a greeting or a face announcing that something amazing is coming. The work is the hook; the next shot pays it.

    An ad that teaches¶

    Making a variable font? Incompatible masters are easy to miss by eye. Open the master view to see them side by side. 30-day trial.

    One angle, one object, one action. It answers “will this help with my job?” inside the ad.

    A fair comparison page¶

    Facts: a fictional editor compared with another named editor on stated criteria. We make the first.

    We make Editor A. This page compares it with Editor B by task.

    Task Editor A Editor B
    Variable font export Yes Yes
    Scripting language Python Python
    Platforms macOS, Windows macOS
    License Perpetual, paid upgrades [CONFIRM: from Editor B's site, dated]

    Choose Editor B if you work only on macOS and already use its plug-ins. Choose Editor A if you need Windows or want to keep a perpetual license.

    Disclose who wrote the page, state the criteria, describe the other product by its own published facts, date the table and say when the other tool fits better. No adjectives about the competitor.

    A news release on our own newsroom¶

    A news release is written for buyers as well as editors and kept permanently on our own news page under the company's name, with prices, eligibility and links to the pages that carry the facts. That is not disguised advertising; a paid placement made to look like reporting is. Pitches go to one writer at a time, naming an article of theirs that makes the news relevant: plain text, no attachments, no "Re:" on a first message.

    One phrase, one page¶

    Each phrase a buyer searches for has one preferred page; other pages link to it. Put the brand beside the generic phrase in the first sentence ("TransType converts a variable font to static fonts"). Research search terms in each language instead of translating the English list. Retired pages redirect.

    Passages that survive being quoted¶

    Question heading: Does Vexy Lines export SVG?

    Answer first: Yes. Vexy Lines exports SVG, PDF and EPS as vector formats, and PNG and JPEG as raster images.

    (The format list follows the Vexy Lines manual pages; the current landing page lists fewer formats. Recheck both before publication.)

    The answer names the product, so it stays true when an answer engine lifts it out of the page. “Yes, it does” would not.

    One product sentence, everywhere¶

    Draft a single approved description and reuse it verbatim on the product page, store listing, video description and press kit:

    Vexy Lines turns a bitmap image into line artwork you can edit and export as vector files. [CONFIRM: approved product sentence]

    Varying the description for freshness teaches readers and answer engines that there are several products.

    Publish the facts yourself¶

    Is there a free version? The demo is free to download. Exporting your artwork requires a license. [CONFIRM OFFER: current demo and license terms]

    If our own page does not state the price and the demo terms, readers and answer engines will take them from an old forum thread.

    Answering in a community¶

    Fictional exchange about a fictional editor:

    I work on Editor A. The kerning disappears because the feature file is not being merged on export [CONFIRM: cause]. In the export profile, turn on [CONFIRM LABEL: option]. If that does not fix it, send the file to support and mention this thread.

    Disclose the affiliation in the first line, put the whole answer in the reply and link only when the linked page adds something.
